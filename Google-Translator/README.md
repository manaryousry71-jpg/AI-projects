# Google Translator – Language Translation App

##Project Overview
This project is a simple Language Translation application developed using Python and Tkinter.
The application allows the user to enter text, select the source language and target language, and translate the text using the Google Translator service through the `deep-translator` library.

##Objectives
* Build a simple and user-friendly translation application.
* Allow users to enter text for translation.
* Provide source and target language selection.
* Translate text between different languages.
* Display the translated result to the user.

##Technologies Used
* Python
* Tkinter
* deep-translator
* GoogleTranslator

##Supported Languages
The application supports the following languages:
* English
* Arabic
* French
* German
* Spanish

##How It Works
1. The user enters the text they want to translate.
2. The user selects the source language.
3. The user selects the target language.
4. The application sends the text to the Google Translator service through `deep-translator`.
5. The translated text is returned and displayed to the user.

##Installation
Install the required library using : pip install deep-translator

##How to Run
Run the Python application using : python translator.py

##Example
Input : Hello, how are you?
Source Language : English
Target Language : Arabic
Output : كيف حالك

##Machine Translation
The project demonstrates the basic concept of Machine Translation, where text written in one natural language is automatically converted into another language.
In this project, the translation service is accessed through the `deep-translator` Python library and `GoogleTranslator`.
